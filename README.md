## 一、 为什么要了解二手暗语？

在二手电商（尤其是闲鱼）的生态中，形成了两套截然不同的使用动机：

1. **对于买家（防割韭菜、看破套路）**：
   - 很多卖家利用黑话制造信息差，隐瞒商品瑕疵。例如：
     - 听到 `买包烟成色`，以为是“外观略有磨损”，实际上是“外壳摔烂、内屏暗病、随时报废”；
     - 听到 `全绿`，以为是“全原装正品”，实际上是“华强北爱思助手改底层数据骗小白”。
2. **对于卖家（合法防封、规则合规）**：
   - 二手平台算法风控极其严苛，标题和详情稍有不慎（如出现官方违禁词、同城约见敏感词）就会导致限流、降权甚至直接封号；
   - 卖家需要使用公认的、合规的、平台允许的日常替代词或谐音（如 `xd价` 代替 最低价，`后台踢我` 代替 私信）。

## 四、 开发者与数据接口 (JSON API)

本项目所有数据在 [`data/slang-dictionary.json`](./data/slang-dictionary.json) 中完全结构化开放，包含：
- `stats`: 词条总量与变体数量
- `categories`: 分类元数据（ID、名称、图标）
- `abbreviations`: 拼音首字母缩写反查表
- `entries`: 完整黑话条目详情（标准名、变体列表、存活状态、百科释义、买卖双向透视）

```bash
# 获取最新完整词典 JSON
curl -O https://raw.githubusercontent.com/{OWNER}/awesome-chinese-secondhand-slang/main/data/slang-dictionary.json
```
